This page records the agents that have been run against Ferrite Cloud. Each row names one agent, how you add Ferrite to it, what was run on each route, and the date of that run. [Connect any agent to your Ferrite account](/developers/connect-any-agent/) has the full setup for every client, including the ones this table does not list.

An agent can reach Ferrite by three routes, and the table has a column for each:

- **Plugin** is the Ferrite plugin installed in the agent. It carries the Ferrite skill, the MCP server entry and the CLI installer.
- **CLI** is the `ferrite` CLI installed on the same computer and registered as the agent's local MCP server with `ferrite mcp-serve`.
- **Hosted MCP** is the remote server at `https://mcp.ferrite.cloud/mcp`, added to the agent's own configuration or as a connector, with sign-in through the browser.
